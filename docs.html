Configuration serveur

Chaque serveur reste isolé.

Les bots sont pensés pour plusieurs serveurs. Les rôles, salons, logs, panels et réglages restent attachés au serveur où ils sont configurés.

  • Pas de partage de configuration entre serveurs.
  • Pas de publication de la base SQLite.
  • Les données publiques du site sont séparées des données Discord privées.

Acces public

Les bots sont disponibles pour votre serveur.

Protect, Support et Game peuvent etre ajoutes a plusieurs serveurs Discord. Chaque installation dispose de sa propre configuration et de ses propres donnees.
