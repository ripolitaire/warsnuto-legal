# WarsNuto legal site

Mini-site statique pour publier les pages légales des bots Discord:

- `index.html`
- `privacy.html`
- `terms.html`
- `styles.css`

Contact officiel utilisé dans les pages: `solitaire.blox@gmail.com`.

## Déploiement conseillé

Tu peux héberger ce dossier gratuitement avec GitHub Pages, Cloudflare Pages ou Vercel.

Après publication, ajoute les liens dans le Discord Developer Portal de chaque application:

- Privacy Policy URL: `https://ton-domaine/privacy.html`
- Terms of Service URL: `https://ton-domaine/terms.html`

Ces pages sont informatives et doivent être adaptées si les bots ajoutent de nouvelles collectes de données ou changent de fonctionnement.
