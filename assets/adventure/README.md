# Assets de l'aventure navigateur

Les illustrations historiques de carte et de boss de ce dossier sont copiees depuis les assets deja utilises par WarsNuto Game. Elles ne sont pas generees par IA.

Le sous-dossier `rpg/` ajoute un decor de port et un avatar generique originaux,
crees avec l'outil de generation d'images puis optimises en WebP. Leur provenance,
leurs prompts et leurs limites sont decrits dans `rpg/SOURCES.md`.

Les sources documentees pour les portraits de boss sont conservees dans `bosses/SOURCES.md`. Les personnages et images One Piece restent la propriete de leurs ayants droit. Ce dossier ne doit pas recevoir de media externe sans verification de son droit d'utilisation.

Les sons de `audio/` sont des effets originaux synthetises pour l'interface. Ils ne reutilisent aucune musique officielle.
